# HireSense AI

HireSense AI is an AI-powered interview and career intelligence platform designed to help candidates improve their hiring readiness through personalized resume analysis, job matching, mock interviews, performance evaluation, and actionable career insights.

## Tech Stack

### Frontend
- React
- Vite
- JavaScript / JSX
- Tailwind CSS
- Framer Motion
- Zustand
- React Query
- React Hook Form
- Zod
- Recharts

### Backend
- Node.js
- Express.js
- MongoDB

## Project Status

🚧 **Currently under active development.**

The frontend foundation and user experience will be developed first. Backend services, database integration, authentication, and AI-powered intelligence modules will be integrated progressively.
